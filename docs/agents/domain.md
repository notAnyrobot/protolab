# Domain Docs

This repo uses one root `CONTEXT.md` and root `docs/adr/` for domain terms and decisions.

## Before exploring

Read `CONTEXT.md` when it exists. Read ADRs in `docs/adr/` that touch the area of work. If these files do not exist, proceed; the domain-modeling skill creates them when terms or decisions are resolved.

## Vocabulary

Use terms defined in `CONTEXT.md` in issues, proposals, hypotheses, and tests. If a needed concept is absent, reconsider the term or note the gap for domain modeling.

## ADR conflicts

Surface any conflict with an existing ADR explicitly before proposing a different decision.
